# AWS Data Engineering Assignments

This repository contains end-to-end Data Engineering assignments demonstrating AWS services, Python, SQL, Pandas, and Machine Learning.


## Project Objective

The objective of this repository is to demonstrate practical Data Engineering skills using AWS, Python, SQL, Pandas, and Machine Learning through real-world assignments.



## Assignments

### Assignment 1
Event-Driven S3 Processing using AWS Lambda and Amazon S3

### Assignment 2
Advanced SQL Transformations using CTEs and Window Functions

### Assignment 3
IoT Data Engineering and Anomaly Detection

### Assignment 4
Predictive Modelling with Pandas and Scikit-Learn
