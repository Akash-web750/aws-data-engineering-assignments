 # Assignment 02 - Advanced SQL Transformations

## Objective

This project demonstrates advanced SQL transformations using PostgreSQL.

The assignment focuses on solving analytical business problems using SQL only, without using stored procedures, cursors or loops.

---

## Database Schema

The project contains four tables.

1. Categories
2. Products
3. Customers
4. Sales

Relationship

Categories
      │
      │
Products
      │
      │
Sales
      │
      │
Customers

---

## Dataset

| Table | Records |
|--------|---------|
| Categories | 5 |
| Products | 20 |
| Customers | 30 |
| Sales | 100 |

## Assignment Tasks

### Question 1

Used

- CTE
- RANK()
- LEAD()
- LAG()

to identify sales patterns.

---

### Question 2

Implemented

- Moving Average
- Top N Products per Category

using Window Functions.

---

### Question 3

Performed complex joins across

- Customers
- Products
- Categories
- Sales

to generate analytical reports.
